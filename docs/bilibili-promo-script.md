## 四、完整旁白文案

### 开场（0:00–0:25）

每天打开电脑，总有那么一些事：重复、枯燥、毫无技术含量——签到、重复点击、机械录入、来回拖窗口……你的手明明可以下班，为什么要让它加班？

今天分享一个我自己做的开源工具：**键鼠工坊 QuickScriptTool**。在 Windows 上，从连点到录制、从找图到 AI 写脚本，一套工具全搞定。

### 产品定位（0:25–1:00）

先看脸。这个界面不是随便套个 Electron 壳——它用的是 **WebView2 现代壳 + C++ 原生引擎**，界面好看，底层轻快。主页四个大模块：连点、录制、宏、脚本定制。

而且它完全**免费、开源**，还有免安装的便携版，解压就能跑。

### 连点（1:00–1:40）

先看最简单的连点。左键右键、自定义间隔，想要更隐蔽还有进阶参数：随机间隔、按下抬起时长、坐标抖动、定点连点、次数上限，全都能调。

重点是它不吃性能、不抢键盘，全局热键随时启停，按住还能当开关用。

### 录制回放（1:40–2:40）

连点只是开胃菜，真正的大招是**录制回放**。把一段操作录下来，它不是简单记几个坐标，而是微秒级的精准时间轴——你操作的节奏、停顿、轨迹，都能原样回放。

录制完还能优化：合并压缩、调整等待，甚至一键把点击转成**找图**，让脚本自己认目标、自己找位置，跨窗口也不怕。

### 宏编辑器（2:40–3:30）

想要更高级？打开宏编辑器，可视化拖拽搭积木：循环、条件判断、变量、跳转、调用其他宏，全都能搭。坐标还支持跨分辨率归一化——换台电脑、分辨率不一样，脚本照样精准。

全程不用写一行代码，备注随手加，脚本还能 JSON 导入导出，方便分享和备份。

### 找图 + OCR（3:30–4:20）

让脚本「长眼睛」的，是找图和 OCR。框选一个目标截图，脚本就能在屏幕上把它找出来：多引擎共识、可调阈值、可视化匹配层，调试一目了然。

OCR 用的是 PaddleOCR，能识别屏幕文字，还能按文字位置做判断——「看到弹窗就关闭、等到指定文字再执行」，这些逻辑都能写进脚本里。

### 窗口模式 + 定时任务（4:20–5:10）

最硬核的是**窗口模式**。把脚本绑定到指定窗口，后台悄悄干活，不抢你的鼠标键盘，你还能同时正常用电脑。虚拟桌面隔离、窗口捕获、后台输入，再配上 Edge 扩展，连网页操作都能桥接。

再加上定时任务：早上 8 点自动签到、整点自动跑宏，真正做到无人值守。

### AI 写脚本（5:10–5:50）

重头戏来了——**AI 写脚本**。在脚本定制页用大白话提需求：「帮我写个脚本，找到图片就点击，找不到就等两秒重试」，它直接给你生成完整的宏，还能现场修改、立刻执行测试。

不会写脚本？没关系，**会说话就行**。

### 技术彩蛋 + 结尾（5:50–6:30）

最后说点硬核的：引擎是 C++ 原生实现，输入注入、时间轴调度、找图引擎全部自研；界面层是 WebView2 壳，原生能力该在哪层就在哪层，绝不塞进网页里冒充。可选的 Interception 后端和虚拟 HID 驱动，技术底子实打实。

下载渠道放在评论区置顶，官网还有**在线体验 Demo**，不用安装就能先玩。

最后提醒一句：脚本工具请用于学习交流和个人自动化，使用前一定遵守对应软件和游戏的规则。

如果你觉得这工具对胃口，**一键三连**，就是我继续更新的最大动力！
