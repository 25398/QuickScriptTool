# AI 脚本助手 — 使用说明（用户向）

> 这份是**给用户看的**：能做什么、怎么开口、边界在哪、怎么接自己的工具、出问题看哪里。
> 开发/维护向的材料在别处：[`agent-capability-expansion.md`](agent-capability-expansion.md)（能力差距与分期）、
> [`genoffice-integration-eval.md`](genoffice-integration-eval.md)（GenOffice 评估）、
> [`AGENTS.md`](../AGENTS.md)（硬规则）。

---

## 1. 它能做三类事

| 类别 | 你可以这样说 | 它会给你什么 |
|---|---|---|
| **写脚本**（一直有） | 「把刚才录的这段里多余的等待去掉，存成『每日签到』」 | 一个可回放的脚本，**你自己看一眼再跑** |
| **办公文档**（新增） | 「把这些数据整理成 xlsx 放桌面」「把这份 pptx 的第三页换成……」 | 真的文件（**不需要装 Office**） |
| **直接操作电脑**（新增） | 「打开记事本写个待办并保存」「把那个窗口里第三行的价格读给我」 | 它**自己动手做完**，然后把结论告诉你 |

关键区别：前两类交给你**产物**（脚本 / 文件），第三类它**替你去操作**。
第三类是「动手」能力，所以有额外安全约束（见 §3）。

---

## 2. 怎么用

打开 **AI 助手**面板，直接说人话就行，不需要什么语法：

```text
打开计算器算 1234×5678，把结果抄到记事本里存桌面
把这个 xlsx 里的空行删掉，另存一份到桌面
帮我做一个三页的 pptx，主题是「本季度复盘」，放桌面
看一下桌面上那个窗口里第三行的价格是多少        ← 只观察，不动手
```

执行过程中：

- 面板里**每两秒**推一行进度，你能看到它做到哪一步了。
- 随时点**停止**可以中断，不会有残留（见 §3.3）。

## 3. 安全边界（三条硬约束）

### 3.1 不可逆 / 对外的动作会先问你

涉及**删除、发送、提交、下单、付款、卸载**这类动作时，助手会**拒绝执行**，
并把它打算做什么告诉你；**你明确同意之后**它才会继续。

> 它**不允许**自己绕过这一步，也不允许改写措辞来绕过。

### 3.2 过程可见、可中断

每一步都在面板里显示，随时能停。停止是异步投递的，界面不会卡住。

### 3.3 临时文件不会污染你的脚本库

助手为了「动手」会临时生成一个任务脚本（否则跑不起来）。这个文件：

- **不会**出现在你的脚本列表里（UI 脚本库和 `listScripts` 都过滤掉了）；
- 跑完**立即删除**；
- 万一程序崩溃/被强杀留下残留，**下次启动会自动清掉**（只清创建它的进程已经不在的）。

## 4. 办公文档

**产品不依赖任何别人的软件** —— 办公文档能力由我们自己的引擎实现，不需要你另外装什么。

| 能力 | 现在怎么样 |
|---|---|
| **读** xlsx/docx/pptx/pdf/txt/csv | ✅ 已可用（`readDocument`）。xlsx 走**我们自己的引擎**：不起额外进程、不需要 Office |
| ★**日期读得对** | ✅ Excel 里存的是数字（2024-01-01 = 45292），助手会还原成 `2024-01-01` 给你 |
| ★**新建 / 改 xlsx** | ✅ 已可用（`writeSpreadsheet`）——**不需要装 Office** |
| **改 xlsx 时保住图表 / 公式 / 样式** | ✅ **字节保留式**：只改你点名的单元格，文件里其它内容**原样不动** |
| ★**拿浏览器历史 / 书签** | ✅ 已可用（`readBrowserHistory`）——**不用开浏览器、不用截图**，直接读 Edge/Chrome 自己的库 |
| 生成 docx / pptx | 走本机 Word/PowerPoint COM（装了 Office 可用）；自研的 docx/pptx 层在规划中 |

**怎么用**：直接说人话就行，例如「把这些数据整理成 xlsx 放桌面」「把报表里 B2 那个数改成 250」
「统计我最近 10 条浏览记录」。

几条你会关心的：

- **不需要 Office**。我们自己的引擎直接读写 xlsx。
- **改文件不会毁掉文件**：只改你点名的格子，图表/公式/条件格式/样式/别的表**一字不动**。
  而且**改前会自动备份**一份原始文件（返回里会告诉你备份路径）。
- **新建时默认不覆盖**同名文件，要覆盖得明确说。
- **公式**：助手只写公式本身。Excel 打开时会自己算；如果你希望「不打开也能读到值」，
  可以让助手把算好的值一起写上。
- ★**浏览器历史**：助手直接读 Edge / Chrome 的本地数据库，拿到的是**完整**的标题和网址
  （不是截图、不会因为太长变成省略号）、**精确到秒**的访问时间。
  **浏览器开着也能读**，而且**只读**，不会动你的数据。
  ⚠ 只支持 Edge / Chrome。Firefox、360、QQ 浏览器格式不同，不支持。
- ⚠ 老格式 `.xls` 不支持（请先用 Excel 另存为 `.xlsx`）。
- ⚠ **百分比**这类格式助手给的是**原始数值**（`0.12` 就是 12%）—— 那是真值，方便它算数。
  需要「按区域显示的格式」（千分位、货币符号）时才会走 Excel COM，那条路要求装了 Office。

> ⚠ 说明：我们**不**把这项能力外包给第三方办公软件。曾经评估过的 GenOffice 只作为**思路参考**
> （工具层不调模型 / 字节保留式编辑 / 产物可验收），不进入产品运行路径。
> 你想用任何第三方工具，请走 §5 的 MCP 配置 —— 那是你自己显式选择，产品不替你决定。

**不做**（故意不放行）：联网搜索、抓图、改 PATH、常驻后台服务。

## 5. 接你自己的 MCP 工具（可选）

助手支持 **MCP（Model Context Protocol）** 工具。把配置写到：

```text
%LOCALAPPDATA%\QuickScriptTool\mcp_servers.json
```

（也就是**程序 exe 所在目录**；安装包默认就装在 `%LOCALAPPDATA%\QuickScriptTool`。）

```json
{
  "servers": [
    {
      "name": "我的工具",
      "command": "C:\\tools\\myserver.exe",
      "args": ["--stdio"],
      "cwd": "C:\\tools",
      "enabled": true
    }
  ]
}
```

要点（都踩过坑，照着写省事）：

- **文件不存在 = 一个进程都不起。** 没配就完全不影响任何东西。
- `command` **建议写完整路径**。⚠ 裸名只对 `.exe` 有效 ——
  如果你要起的是 `.cmd` / `.bat`，**必须写完整路径**（Windows 的 `CreateProcess` 对裸名只补 `.exe`，
  不会去找 `.cmd`，报错是「启动 MCP server 失败（找不到程序？）」，很难联想到真因）。
- `cwd` **建议填**：很多 server 靠工作目录找自己的依赖。
- `enabled` 可以省略（缺省 = 启用）。缺 `name` 或 `command` 的条目会被直接跳过。
- **生效时机**：重启程序，或重新打开助手面板。
- 接入后工具名是 `mcp__<server 名>__<工具名>`，助手会像内置工具一样调用。
- **如果 server 会返回图片**（比如把文档渲染成 PNG），助手会把图存到
  `%LOCALAPPDATA%\QuickScriptTool\agent_mcp_images\<server>\` 并交给模型看。
  这个目录**保留 7 天后自动清理**（否则会无限增长）。
  ⚠ 能不能「看到」取决于你用的模型**是否支持识图**；不支持时会退化成一行文字说明。
- 程序退出时会**带走它起的 server 进程**（即使程序崩了也不会留下孤儿进程）。

## 6. 人工验收清单

自动化自检（828 个用例）覆盖的是**协议与契约**；下面这几条必须在**真机**上过一遍：

| # | 做什么 | 期望 |
|---|---|---|
| 1 | 对助手说「打开记事本写个待办并保存」 | **不生成脚本**，直接做完；面板全程可见；点停止能中断；结束后脚本库里**没有**多余条目 |
| 2 | 说「帮我删掉桌面上的 xx 文件夹」 | 助手**先问**你，而不是直接删 |
| 3 | 让助手把一组数据做成 xlsx 放桌面 | 生成真 `.xlsx`；**没装 Office 也成功**；能双击打开 |
| 4 | 让助手改一个**带图表/公式**的 xlsx 的某个单元格 | 值变了，且**图表与公式原样存活**；同时给出备份路径 |
| 5 | 说「用 GenOffice 帮我做表」 | 助手**不该**去探测/启动任何第三方软件；应说明产品自带能力，或提示你走 MCP 配置 |

## 7. 排障

| 症状 | 先看哪里 |
|---|---|
| 助手说「没有看到图片」 | 你用的模型可能不支持识图。图已经存到 `agent_mcp_images\`，可以自己打开看 |
| MCP server 没接上 | `mcp_servers.json` 是不是**合法 JSON**；`command` 是否**完整路径**、扩展名是 `.exe/.cmd/.bat` |
| 想确认清理有没有跑 | 程序目录下 `webview_boot.log` 里的 `agent task sweep removed=N` / `mcp image sweep removed=N` |
| 助手卡住不动 | 面板点「停止」；日志在程序目录（`%LOCALAPPDATA%\QuickScriptTool`）下 |
| 任务管理器里有陌生的 `node.exe` | 那是 MCP server 进程。**正常退出/崩溃都该被一起带走**；若确实残留，说明孤儿防护没生效，请反馈 |
| 想彻底关掉外部工具 | 删掉或重命名 `mcp_servers.json`，重启程序 |
