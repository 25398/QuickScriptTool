## 一点五、已经验证到什么程度（真机证据）

```
[4] ★ 输入框长什么样：div[contenteditable='true'] 960x24 → 富文本(contenteditable)
[5] ★ 能不能把字写进去：回读长度=5  内容='QST探测'   → 写入成功且已回读确认
[7] 真发一条消息：用时 6022ms，读回 43 字 → 「你好😊，有什么可以帮你的吗？」
```

真实产品功能（脚本里 `aiModelName = "doubao-web"` 的 `aiTextAnalysis` 动作）：

```
[网页AI] provider=doubao 轮次=1 新对话=1 提示词=1462 字
[网页AI] 收到新回答：2 字，块 9→11，用时 5272ms
AI文字分析 [doubao-web]：完成 → aiResult = 15      ← 问的是 7+8
```

复现脚本：`build\Release\scripts\_webai_e2e_test.json`（一个 AI 文字分析动作，问豆包 7+8）。

⚠ **一个重要行为**：如果你**自己填过 API Key**，网页 AI **不会**抢你的配置 ——
AI 功能仍走你自己的模型（实测：留空模型名时走的是 `deepseek-v4-flash`）。
要让某个动作走网页 AI，就在动作里**显式选 `doubao-web`** 这个模型。

## 三、怎么看结果

- `[OK]` = 正常
- `[!!]` = 有问题，**把那几行复制给我**

探针会依次打印：

| 段 | 内容 |
|---|---|
| `[0]` | 桥在不在、扩展连没连上 |
| `[1]` | 扩展认得哪些站点（豆包/DeepSeek/元宝） |
| `[2]` | 浏览器里有哪些可抓取的标签页 |
| `[3]` | 能不能 attach 到豆包那个标签页 |
| `[4]` | ★ 豆包的输入框是**富文本**还是普通输入框 |
| `[5]` | ★ 能不能把字写进去（**它自己会回读确认**，写完即清空，不发消息） |
| `[6]` | ★ 能不能读回豆包的回答 |

**最关键的是 `[5]` 那两行**：

```
  [OK]  ★★ 写入成功且已回读确认 —— 富文本这一关过了！
        **回读长度=5**  内容='QST探测'
```

回读长度 > 0 就是**真的写进去了**（不是"接口说成功"）。

想跑真正的端到端（**会真的发一条消息给豆包**）：

```
web_ai_probe.cmd --send "你好"
```

## 四、开关说明（当前**已开启**）

开关就是一个文件（**不存在 = 功能关闭**，产品不主动依赖任何外部软件）：

```
D:\other\software\build\Release\web_ai_config.json
```

内容（现在就是这个）：

```json
{
  "enabled": true,
  "provider": "doubao"
}
```

改 `enabled` 或删掉文件即关闭，**需要重启软件生效**。开启后：

1. 模型列表里多出一条 `doubao-web`（指向本机端点）；
2. 如果你**从来没填过**任何 API Key，默认模型会自动指向它 —— 于是 AI 文字分析 /
   对话式脚本助手 / AI 动作执行开箱可用；
3. 如果你填过自己的 API Key，**一律以你的配置为准**，它只是列表里多一条可选档
   （要让某个动作走网页 AI，就在动作里显式选 `doubao-web`）。

关闭时软件会把**它自己加的**那条模型档案清掉（你自己加的档案一律不动）。

> 文件可以用记事本写：**带不带 BOM 都能读**（这一点专门用自检钉住了 ——
> 记事本「另存为 UTF-8」与 PowerShell 的 `Set-Content -Encoding UTF8` 都会写 BOM）。

## 五、常见问题

**Q：探针报「打不开桥的 HTTP 口」，或者 502？**
A：软件没在跑。回第 2 步。502 是**本机代理**回的，不是软件的问题。

**Q：探针报 404 / 501？**
A：跑的是旧版软件（新端点是这次加的），或者处理器没注册。重新构建 + 重启。

**Q：探针报「扩展：离线」？**
A：软件是好的，是扩展没连上。点一下工具栏的「键鼠工坊」图标唤醒它，
或在 `edge://extensions/` 点「重新加载」⟳；软件启动后 30 秒内它也会自己连回来。

**Q：`[5]` 写入失败？**
A：说明 `execCommand`/CDP 对豆包这个富文本编辑器不生效。**把那几行复制给我**，
我按站点改选择器或换写入通道（这是已知风险点，不算意外）。

**Q：`[6]` 读不到回答？**
A：先手动在豆包页面里问一句，让它页面上**有一条回答**，再重跑 —— 探针读的是
"页面上最后一条助手回答"。

**Q：我想改扩展代码，改了没生效？**
A：扩展有两份目录：**源码** `extension\edge`，**构建副本** `build\Release\extension\edge`。
浏览器加载的是后者。跑一次同步：

```
python tools\verify\web_ai_live_probe.py --sync
```

然后在 `edge://extensions/` 点「重新加载」⟳。
