四页主界面

连点 / 录制 / 宏 / 脚本定制四个主 Tab，常用操作一键直达；全局热键与托盘常驻，随时启停。

主界面

可视化宏编辑

动作树 + 拖拽嵌套，支持备注、批量编辑、变量与条件（If/Else、循环、goto），复杂逻辑也能看得清。

宏编辑器

录制回放

键鼠录制 + 精密时间轴（微秒级），录制后可优化整理、去抖合并，还能一键转为找图点击。

录制器

找图 / OCR

模板匹配（多引擎、阈值、缩放）、区域截图与匹配叠加层；PaddleOCR 文字识别，UI 内可视化调试。

图像引擎

窗口模式

绑定目标窗口后台执行宏，不抢用户焦点；支持虚拟桌面隔离、FakeFocus、浏览器类（CDP / Edge 扩展）输入。

后台执行

定时任务与托盘

录制 / 宏按小时、每日、每周或自定义时间自动运行；全局启停热键 + 系统托盘，关闭后仍在后台值守。

自动化

AI Agent 脚本定制

对话式描述需求，AI 直接生成或修改宏与定时任务，支持工具调用、变更撤销，看不懂的脚本也能问。

AI Agent

Web 渲染 UI

WebView2 壳 + Web 前端渲染，现代、可交互、主题可换；官网在线 Demo 就是真实产品前端本身。

极光 Arctic
STEP 01

录制或编写

用录制器记下真实键鼠轨迹，或在宏编辑器里可视化搭建动作树，AI 助手也能帮你写。

STEP 02

优化整理

批量删减、等待时间调整、移动合并 / 压缩，必要时把点击升级为找图点击，脚本更稳。

STEP 03

定时或手动运行

设全局热键即启即停，或交给定时任务；窗口模式下绑定目标窗口后台执行，不打扰你操作。

架构

现代壳 + 原生引擎

界面交给 Web，能力留在原生：两全其美，也不牺牲性能。

WebView2 壳 + Web 前端

主界面由 WebView2 承载 Web 前端渲染（与本站在线 Demo 同一套 UI），现代、可交互、易迭代。

  • 连点 / 录制 / 宏 / 脚本定制四页
  • 可视化宏编辑器与主题系统
  • 官网 Demo 即产品前端本身

C++ 引擎 + 原生模块

脚本解析、执行调度、录制时间轴、找图 / OCR、窗口模式、输入后端等能力由 C++ 引擎提供。

  • 精密时间轴与宏变量 / 条件执行
  • 模板匹配与文字识别引擎
  • 窗口模式后台执行链路

DesktopTools 常驻原生

选区、找图叠层、OCR 叠层、准星、全局热键捕获与托盘等必须贴近系统的能力，保持原生实现，不塞进 Web。

  • 全局热键与脚本热键
  • 屏幕选区与匹配叠加层
